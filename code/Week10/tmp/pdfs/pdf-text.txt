a. Khái niệu về API
➢ API là viết tắt của Application Programming Interface (giao diện lập trình ứng dụng), là
API là “cầu nối” giúp các phần mềm khác nhau nói chuyện và làm việc với nhau.
➢ Có nhiều loại API như:
• REST (Representational State Transfer): Chúng có đặc điểm là dựa dựa trên giao
thức HTTP, sử dụng JSON làm định dạng dữ liệu chính. Ưu điểm: Nhẹ, linh
hoạt, dễ học và tương thích tốt với các ứng dụng Web/Mobile.
Trang 1\n\n===== PAGE 2 =====\n• SOAP (Simple Object Access Protocol): Đặc điểm: Sử dụng định dạng dữ liệu
XML và có quy định rất khắt khe về bảo mật, cấu trúc. Ưu điểm: Tính bảo mật
cực cao, thường dùng trong các hệ thống ngân hàng hoặc giao dịch tài chính lớn.
• GraphQL: Được phát triển bởi Facebook, cho phép người dùng truy vấn đúng
những gì họ cần (không thừa, không thiếu). Ưu điểm: Hiệu quả hơn REST khi
cần lấy dữ liệu phức tạp từ nhiều nguồn khác nhau.
• gRPC (Google Remote Procedure Call): Sử dụng giao thức HTTP/2 và định dạng
nhị phân (Protocol Buffers) thay vì văn bản. Uu điểm: Tốc độ cực nhanh, thường
dùng để kết nối các Microservices trong hệ thống lớn

Trang 20\n\n===== PAGE 21 =====\nKhi khác hàng muôn mua sản phẩm nào thì bấm vào button. Khi khách hàng chọn mua một
sản phẩm thì sẽ có hội thoại xác nhận. Khách hàng có thể chọn nhiều sản phẩm. Khi khách
hàng hoàn thành việc mua hàng, khác hàng có thể bấm vào biểu tượng giỏ hàng trên thanh
công cụ hoặc bấm vào Giỏ hàng trong Drawer.
Màn hình giỏ hàng sẽ hiển thị thông tin của các sản phẩm mà khách hàng đã chọn. Nếu khách
hàng chưa chọn sản phẩm nào thì sẽ thông báo là « Bạn chưa có sản phẩm nào trong giỏ
hàng ». Với mỗi sản phẩm trong giỏ hàng, khách hàng có thể bấm vào biểu tượng để loại bỏ
